# Submission Checklist

## Required by the assessment

- [x] Accessible repository code and run instructions
- [x] `validation_predictions.csv` with exactly 12,000 rows and `load_id,predicted_rate`
- [x] PDF report with validation/split approach and `candidate_december.png`
- [x] 2–3 minute Loom script prepared in `LOOM_SCRIPT.md`

## Before sending

1. Push this repository to GitHub and make it accessible to the recruiter.
2. Open the GitHub README from an incognito/private browser to verify accessibility.
3. Record the Loom using `LOOM_SCRIPT.md`.
4. Paste the real Loom URL into the application/submission form.
5. Attach `validation_predictions.csv` and the PDF report if the submission form asks for direct files.
